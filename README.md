# PocketSmart AI
## AI Powered Smart Budget and Recommendation Assistant

### 1. Project Overview
PocketSmart AI is an AI-powered smart budget and recommendation assistant that helps users plan their expenses and find suitable products and services within their budget.

The system uses Generative AI to provide personalized recommendations for home interiors, party planning, and jewelry selection.

### 2. Problem Statement
Planning expenses for home decoration, parties, and jewelry shopping can be difficult because of different prices, products, and service providers.

PocketSmart AI helps users make better decisions by generating budget-friendly recommendations based on their needs and preferences.

### 3. Objectives
- To provide personalized budget-based recommendations.
- To help users manage expenses effectively.
- To recommend products and services from different platforms.
- To simplify home interior and party planning.
- To suggest jewelry based on occasion and personal preferences.
- To use AI to make decision-making easier.

### 4. Key Features

#### 4.1 Home Interior Budget Planner
- Accepts the user's total budget.
- Collects room and decoration preferences.
- Suggests furniture, lighting, and decorative items.
- Provides budget-friendly recommendations.

#### 4.2 Party Budget Planner
- Accepts the event budget and guest count.
- Collects event type and venue preferences.
- Suggests catering, decorations, and venues.
- Helps allocate the budget across event requirements.

#### 4.3 Jewelry Recommendation System
- Accepts the user's budget and occasion.
- Considers style preferences.
- Supports optional outfit image input.
- Suggests jewelry matching the occasion and outfit.

#### 4.4 AI-Powered Recommendations
- Uses Google's Gemini AI model.
- Processes user requirements and budget details.
- Generates personalized suggestions.
- Can recommend options from platforms such as Amazon, Flipkart, IKEA, Swiggy, Zomato, and OYO.

### 7. System Workflow
1. The user opens the application.
2. The user selects a planning category.
3. The user enters their budget and preferences.
4. The system processes the provided information.
5. Gemini AI generates suitable recommendations.
6. The system displays the recommendations to the user.
